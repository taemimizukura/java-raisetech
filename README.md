## 11_Intellijの便利機能

### Intellij IDEAのショートカットキー

https://pleiades.io/help/idea/mastering-keyboard-shortcuts.html

- `Alt + Shift + 矢印キー`  行の上下移動
- `Shift + Delete` 現在行の削除
- `Alt + マウスで選択`マルチカーソル機能 同時に編集できる
- `Alt + 1`コードの画面が広くなる
- `Ctrl + Shift + F`複数ファイル内検索
- `Ctrl + Shift + V`コピー履歴から貼り付け
- `Alt + Enter` クイックフィックス 便利機能の呼び出し
- `Ctrl + Alt + L`コードの整形
- `Ctrl + Alt + V`変数の抽出 式などを選択してから
- `Ctrl + B` 宣言のジャンプ
- `Ctrl + Alt + B`実装クラスにジャンプ
- `Ctrl + Alt + N`選択箇所の処理を戻す,
- `Ctrl + Alt + F7`変数やクラスが使われている箇所にジャンプ
- `Ctrl + Alt + M`メソッド
- `Ctrl + Alt + F`フィールドを抽出
- `Ctrl + H` 型の階層の表示、継承関係
- `Alt + Ctrl + H`呼び出し先が見られる
- `Ctrl + F6`シグネチャーの変更 右クリック→リファクタリングでも出る
